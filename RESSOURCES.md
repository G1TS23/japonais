# Ressources — annotées

Sélection resserrée, classée par usage. Inutile de tout prendre : un manuel pivot,
un outil SRS, une source d'écoute et une de lecture par phase suffisent.

## Manuels (ossature grammaticale)

| Ressource | Niveau | Notes |
|---|---|---|
| **Genki I & II** (3ᵉ éd.) | N5–N4 | Le standard francophone/anglophone. Clair, progressif, cahier d'exercices + audio. Pivot recommandé pour les Phases 1–2. |
| Minna no Nihongo I & II | N5–N4 | Alternative « tout en japonais » (avec livre de traductions FR/EN à part). Plus sec, très complet, orienté cours. |
| **Tobira: Gateway to Advanced Japanese** | N3 | Référence de transition vers l'intermédiaire. Textes authentiques, tout en japonais. |
| **Quartet I & II** | N3–N2 | Successeur moderne de Genki, oriente vers les 4 compétences. Bonne alternative à Tobira. |
| **Shin Kanzen Master** (新完全マスター) N3/N2/N1 | N3–N1 | Séries par compétence : 文法 (grammaire), 読解 (lecture), 聴解 (écoute), 語彙 (vocab), 漢字. *La* référence pour préparer chaque JLPT. Dense. |
| Sou Matome (総まとめ) N3/N2/N1 | N3–N1 | Plus léger, format « 6 semaines par livre ». Bon pour un premier passage avant Shin Kanzen Master. |
| Tae Kim's Guide to Japanese | N5–N4 | Gratuit, en ligne. Explique la grammaire par la forme neutre d'abord. Bon complément. |
| Imabi | N5–N1 | Gratuit. Extrêmement détaillé, presque linguistique. À consulter ponctuellement, pas à suivre linéairement. |
| Cure Dolly — *Organic Japanese* (YouTube) | N5–N4 | Gratuit. Modèle mental de la grammaire (rôle de が, structure profonde). Voix synthétique déroutante mais contenu apprécié. |
| *A Dictionary of (Basic/Intermediate/Advanced) Japanese Grammar* (DoJG) | tous | Ouvrage de référence, 3 volumes. À consulter pour la nuance exacte d'une tournure. |

## SRS / vocabulaire / grammaire espacée

| Ressource | Usage |
|---|---|
| **Le site** (`web/`) | SRS pivot pour ce programme — moteur FSRS intégré, deck N5 fourni (718 mots). Pas besoin d'Anki pour le vocabulaire de base. |
| **Anki** | Utile uniquement pour ce que le site ne fait pas encore : sentence mining (créer ses propres cartes) à partir du N3/N4, ou decks N4+ en attendant qu'ils soient ajoutés au site. Gratuit (sauf iOS), synchro AnkiWeb. |
| Decks **JLPT Tango N4→N1** | Pour compléter le vocabulaire une fois le deck N5 du site terminé, tant que les paliers suivants n'y sont pas encore. |
| **Yomitan** (extension navigateur) | Dictionnaire pop-up sur n'importe quelle page + création de cartes Anki en un clic. Indispensable pour le sentence mining dès le N4. |
| **10ten Reader** | Équivalent de Yomitan, alternative. |
| **Bunpro** | SRS *de grammaire*, parcours N5→N1, avec exemples et liens vers explications. Complément du manuel — le site ne couvre pas encore la grammaire (prévu à l'étape Quiz). |
| **jpdb.io** | Analyse un texte/média et sort le vocabulaire par fréquence + SRS intégré. Utile pour préparer un livre ou un anime. |
| **WaniKani** | SRS dédié kanji : radicaux → kanji → vocabulaire, ~60 niveaux. Payant. Très structuré ; certains le trouvent lent au début. |

## Dictionnaires

| Ressource | Notes |
|---|---|
| **Jisho.org** | Dictionnaire en ligne de référence. Recherche par sens, kanji, radical, tracé. |
| **Takoboto** | Appli mobile hors-ligne, bonne pour réviser en déplacement. |
| **OJAD** | *Online Japanese Accent Dictionary* : accent de hauteur des mots et des phrases, avec courbes. |
| **DeepL / dictionnaires bilingues** | Pour dépanner, pas pour apprendre. Ne jamais s'y fier pour une nuance. |

## Écoute — par niveau

| Ressource | Niveau | Format |
|---|---|---|
| **Comprehensible Japanese** (Yuki) | débutant → interm. | YouTube, input visuel très guidé. Playlists par niveau. |
| **Nihongo con Teppei for Beginners** | débutant | Podcast, épisodes courts, japonais simple lent. |
| **Nihongo con Teppei** (série principale) | interm. | Podcast quotidien, japonais naturel mais accessible. |
| Japanese with Shun / Sakura Tips / YuYu Nihongo Podcast | interm. | Podcasts pour apprenants, sujets du quotidien. |
| **日本語の森** (Nihongo no Mori) | N3–N1 | YouTube, explications de grammaire *en japonais* + prépa JLPT. |
| Miku Real Japanese | interm.–avancé | Japonais familier réel, expressions, nuances. |
| Dramas / anime avec sous-titres **japonais** | N3+ | *slice of life* d'abord (よつばと系, 日常物). Éviter sous-titres FR. |
| Podcasts natifs généralistes, JT NHK, YouTube natif | N2+ | Objectif Phase 4 : vitesse normale, sans sous-titres pour une partie. |

## Lecture — par niveau

| Ressource | Niveau | Notes |
|---|---|---|
| **Tadoku graded readers** (tadoku.org) | débutant+ | Lecteurs gradués gratuits (PDF), niveaux 0 à 5. Commencer *sous* son niveau. |
| **NHK Easy News** (news.web.nhk/news/easy) | N4–N3 | Actus réécrites en japonais simple, avec furigana et audio. |
| **Satori Reader** | N4–N3 | Histoires originales avec furigana réglable, notes de grammaire, audio natif, dictionnaire intégré. Payant, très bien conçu. |
| **Watanoc** | N4–N3 | Webmagazine gradué gratuit. |
| Manga *slice of life* : よつばと！, しろくまカフェ, からかい上手の高木さん | N3 | Vocabulaire concret, contexte visuel, dialogues courts. |
| NHK / 朝日新聞 (articles normaux), blogs, Wikipédia JP | N2+ | Objectif Phase 4. Lire avec Yomitan puis sans. |
| Romans grand public / *light novels* / essais | N2–N1 | Choisir un titre qui motive vraiment ; préparer le vocab avec jpdb.io. |

## Production (oral & écrit)

| Ressource | Usage |
|---|---|
| **italki** / **Preply** | Tuteurs payants à l'heure. Cours structurés ou conversation libre avec correction. 1–2×/mois dès le N3, hebdo au N2. |
| **HelloTalk** / **Tandem** | Échange linguistique gratuit. Correction mutuelle de textes courts, messages vocaux. |
| **Journaly** / carnet perso | Tenir un journal en japonais, se relire, faire corriger. |
| **Shadowing** — livres *Shadowing: Let's Speak Japanese!* (シャドーイング 日本語を話そう) | Répétition simultanée d'audio natif transcrit. Prosodie + fluidité. |
| IA (Claude / ChatGPT) | Relecture-correction commentée, partenaire de conversation calibré, exemples de grammaire. À croiser avec une source fiable pour les points fins. |

## Kanji

| Ressource | Approche |
|---|---|
| Via le vocabulaire (le site + Yomitan) | Recommandé par défaut : chaque mot fixe ses kanji en contexte. |
| **WaniKani** | Parcours radicaux → kanji → vocab, SRS intégré, ~2 000 kanji. Payant. |
| **KameSame** | SItué en complément de WaniKani, entraîne la production (sens → mot). |
| *Remembering the Kanji* (Heisig) | Écriture + distinction de ~2 200 kanji, sans lectures. En complément uniquement. |
| **jpdb.io** kanji | Ordre par fréquence, SRS. |

## Communautés / méthodes

| Ressource | Notes |
|---|---|
| r/LearnJapanese | Forum généraliste actif, wiki de démarrage solide. |
| TheMoeWay (learnjapanese.moe) | Guide gratuit orienté immersion + sentence mining, très détaillé sur l'outillage. |

> Les méthodes « tout immersion » (TheMoeWay, Refold) et « manuel d'abord » (ce
> programme) ne s'opposent pas : ce programme garde un manuel pivot pour la
> structure *et* intègre l'immersion/sentence mining tôt. Pioche l'outillage
> d'immersion chez eux, garde la progression grammaticale d'ici.
